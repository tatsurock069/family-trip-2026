# family-trip-2026

関家の天橋立・伊根旅行用Webアプリです。

## GitHub Pages公開手順

1. このフォルダの中身をリポジトリ直下へアップロード
2. GitHubの `Settings` → `Pages`
3. `Deploy from a branch`
4. Branchを `main`、フォルダを `/ (root)` にして保存
5. 数分後に表示されるURLをSafariで開く
6. Safariの共有ボタン → `ホーム画面に追加`

## 主な機能

- 初日プランA/B切替
- 費用シミュレーター
- ロピア買い出しチェック
- BBQ調理ガイド
- 撮影チェック
- 持ち物チェック
- 子どもミッション
- チェック状態の端末内保存
- PWA / オフライン表示対応
